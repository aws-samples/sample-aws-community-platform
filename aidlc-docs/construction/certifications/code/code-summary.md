## Defects caught during generation (by tests, not review)
1. **Gate-level UGL denial**: mapping `verificationQueue`/`decideClaim` straight to the matrix's `group`-scoped row denied UGLs at the gate — the group binding needs the claim's `creditedGroupId`, which is only known after a read. Fixed with the OP_AUTHZ "defer-group" marker: the gate checks rule existence; the service enforces the binding (with 404-not-403). The authz-matrix suite caught it on first run.
2. **Quarantine message masked by existence check**: a quarantined evidence file is deleted by the consumer, so checking `object_exists` before the verdict told the member "file has not been uploaded" — inviting a re-upload of the same malware. Verdict check now precedes the existence check.
3. **`setdefault` froze renamed badges**: `certName` denormalised at submission was never overwritten by the definition join, so renaming a certification didn't rename badges (US-5.2). Now an explicit overwrite with the denormalised value as deleted-definition fallback.
4. (Tooling) **stage_gsis.py information loss**: staging down to GSI1 rewrote the template, so a later `1 2` run couldn't find GSI2's definition — fixed with a complete-set cache; round-trip verified byte-identical.
