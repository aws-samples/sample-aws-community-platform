# Build Instructions — Content Library Rework

## Prerequisites

| Requirement | Version | Notes |
|---|---|---|
| Python | 3.12 | Events + Contributions services |
| Node.js | 20.x | Frontend build |
| npm | 10.x | Frontend dependencies |
| AWS SAM CLI | latest | Infrastructure packaging |
| boto3 / moto | pinned in requirements | Test dependencies |

| Variable | Source | Required |
|---|---|---|
| `TABLE_NAME` | events-data stack output | Yes |

| `FILE_SHARE_BUCKET` | foundation stack output | Yes |

## Build Steps

### 1. Install Python dependencies (Events service)

```bash
pip install -r services/events/requirements.txt
```

### 2. Install Python dependencies (Contributions service)

```bash
pip install -r services/contributions-scoring/requirements.txt
```

### 3. Build frontend SPA

```bash
cd frontend
npm install
npm run build
```

Expected output: `dist/` folder with `index.html`, `assets/index-*.js`, `assets/index-*.css`. Build completes in ~2s. The chunk size warning (`> 500 kB`) is pre-existing and acceptable — not introduced by this change.

### 4. Lint checks

```bash
# Python
ruff check services/events/src/
ruff check services/contributions-scoring/src/

# TypeScript
cd frontend && npx tsc --noEmit
```

### 5. Infrastructure lint

```bash
cfn-lint infra/services/service-events-data.yaml
cfn-lint infra/services/service-events-app.yaml
cfn-lint infra/root-template.yaml
```

### 6. Contract mock regeneration

Regenerate the events service mock to reflect the new `/library` routes:

```bash
# Verify openapi contract is valid
python3 -c "import yaml; yaml.safe_load(open('contracts/services/events/openapi.yaml'))"
```

### 7. API edge regeneration

Add `library` to the base-path routing and regenerate:

```bash
python3 infra/tools/gen_api_edge.py
# Verify library routes appear
grep "library" infra/api-edge.yaml
```

## Troubleshooting

### `ModuleNotFoundError: library_repository` in tests
- Ensure pytest is run from the workspace root with the service `src/` on the path
- Check `services/events/conftest.py` for `sys.path` setup

### Frontend build error: `Cannot find module './features/ContentLibraryPage'`
- Verify `frontend/src/features/ContentLibraryPage.tsx` exists
- Run `npx tsc --noEmit` to see exact TypeScript errors

### CloudFormation: `GSI3 attribute not found`
- Deploy `service-events-data` stack first — GSI3 removal is a single `UpdateTable`
- Wait for `UPDATE_COMPLETE` before deploying the app stack
